Activité 6.3 : les vers parasites, de l’assiette à l’organisme

101-813-MA — Introduction à la microbiologie alimentaire

Durée : environ 25 minutes. Trois jeux à faire dans l’ordre, sans quitter la page : comment les vers nous rendent malades, une enquête sur six cas, puis ce qui détruit (ou non) les larves et les kystes. Les réponses se trouvent dans les diapositives sur les vers parasites d’aujourd’hui.
